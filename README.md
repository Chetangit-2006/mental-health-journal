# Mental Health Journal and Chatbot


A full-stack mental wellness application that allows users to privately record journal entries, track moods, and interact with an AI-powered wellness assistant.



\## Features



\- User registration and login

\- JWT authentication

\- Private journal entries

\- Create, edit and delete journals

\- Mood tracking

\- Mood analytics

\- AI wellness chatbot

\- Chat history

\- MongoDB data persistence

\- Responsive UI



\## Tech Stack



\### Frontend

\- Next.js

\- React

\- TypeScript

\- Tailwind CSS



\### Backend

\- Node.js

\- Express.js

\- JWT

\- bcrypt



\### Database

\- MongoDB Atlas

\- Mongoose



\### AI

\- Google Gemini API
